# Construction archive

These files record the plans, acceptance criteria, and milestone prompts used to
build the original Easy Plugin vertical slice.

They are retained for historical context and framework maintenance. They are not
instructions for creating a new audio plugin from this template, and references
inside them use the repository layout that existed during construction.

For current plugin-author guidance, start with the repository `README.md`,
`AGENTS.md`, and `docs/STARTING_A_PLUGIN.md`.
